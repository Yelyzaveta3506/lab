## 1. Мета та завдання роботи

**Мета роботи:** Набути практичних навичок створення клієнтської інтерактивності веб-додатків за допомогою сучасного JavaScript (ES6+), опанувати асинхронне завантаження даних у форматі JSON через Fetch API, динамічну маніпуляцію DOM-елементами, роботу з `localStorage`, а також закріпити методи формування ефективних промптів для Google Gemini та публікації проєкту на GitHub Pages.

**Основні завдання:**
1. Перенести та підготувати структуру веб-сайту «TechPulse», розробленого в межах Лабораторної роботи №2, для інтеграції JavaScript-логіки.
2. Створити структурований файл даних `products.json` відповідно до вимог Варіанта №1 (онлайн-магазин електроніки).
3. Використати Google Gemini для планування архітектури, генерації даних та написання модульного JavaScript-коду.
4. Реалізувати асинхронне завантаження товарів через Fetch API (`async/await`) з обробкою помилок (`try/catch`).
5. Впровадити динамічну генерацію Bootstrap-карток товарів із відображенням знижок, рейтингу та статусу наявності.
6. Реалізувати комбіновану фільтрацію (за категорією, брендом, наявністю), миттєвий пошук за назвою та сортування (за ціною, рейтингом і популярністю).
7. Розробити функціонал кошика зі збереженням стану в `localStorage` та динамічним оновленням лічильника в шапці сайту.
8. Покращити користувацький досвід (UX) за допомогою індикатора завантаження, плавних анімацій появи карток і спливаючих сповіщень.
9. Протестувати роботу скриптів у DevTools та опублікувати оновлений проєкт на GitHub Pages.

### Етап 2: Робота з Google Gemini (Генерація та ітеративне покращення)

#### Запит 1 (Планування функціональності та архітектури JS-модуля):
> **Промпт до Gemini:**  
> *"У мене є адаптивний сайт інтернет-магазину електроніки 'TechPulse' на Bootstrap 5 з попередньої лабораторної роботи. Мені потрібно додати клієнтську інтерактивність на чистому JavaScript: асинхронне завантаження каталогу з файлу products.json через Fetch API, динамічний рендеринг карток, комбіновану фільтрацію (категорія, бренд, наявність), миттєвий пошук за назвою, сортування та кошик зі збереженням у localStorage. Допоможи спланувати модульну структуру файлу script.js та список необхідних HTML-ідентифікаторів для зв'язування DOM-елементів."*

**Виконані дії:**
- Використано локальні змінні стану та змінні кошика, обраних товарів і порівняння всередині модулів `script.js`.
- Узгоджено ID та data-атрибути керування в `index.html` (`#grid`, `#searchInput`, `.filter-cat`, `.filter-brand`, `#inStockFilter`, `#sort`, `#cartN`).

#### Запит 2 (Генерація структури даних `products.json`):
> **Промпт до Gemini:**  
> *"Створи приклад JSON-файлу products.json з масивом даних для інтернет-магазину електроніки (категорії: smartphones, laptops, tablets). Кожен об'єкт має містити такі поля: id (число), name (рядок), category (рядок), price (число), oldPrice (число або null, якщо знижки немає), brand (рядок), rating (число від 1 до 5), image (шлях до зображення, наприклад 'img/iphone15.jpg'), inStock (булеве значення true/false), description (короткий опис). Створи 8 об'єктів різних брендів і категорій із реалістичними даними та цінами у гривнях українською мовою."*

**Виконані дії:**
- Згенеровано та збережено файл `products.json` із 20 позиціями електроніки брендів Apple, Samsung, Lenovo, ASUS, Xiaomi у трьох категоріях (`smartphones`, `laptops`, `tablets`).
- Додано акційні товари з заповненим полем `oldPrice`, товари без знижки (`oldPrice: null`), а також позиції зі статусом `inStock: false` для перевірки блокування кнопки покупки.

#### Запит 3 (Генерація JavaScript-функцій каталогу та кошика):
> **Промпт до Gemini:**  
> *"Напиши набір JavaScript-функцій для роботи каталогу та кошика інтернет-магазину з використанням Bootstrap 5:  
> 1. `loadAndInitialize()` — асинхронно завантажує дані з `products.json` за допомогою `fetch` та `async/await` з обробкою помилок (`try/catch/finally`).  
> 2. `initializeCatalog(products)` та `cardHTML(product)` — приймають масив товарів і динамічно рендерять картки в `#grid` із закресленою старою ціною `oldPrice`, рейтингом, статусом наявності та кнопкою «Додати в кошик».  
> 3. `renderCatalog()` — об'єднує пошук за назвою і одночасну фільтрацію за категорією, брендом, наявністю та ціною, а також сортування за ціною, рейтингом і популярністю.  
> 4. `renderCart()` — відновлює та оновлює кошик у `localStorage`, кількість товарів у шапці та вміст drawer кошика."*

**Виконані дії:**
- Реалізовано асинхронну функцію `loadAndInitialize()` із перевіркою HTTP-відповіді (`if (!response.ok)`) та виведенням повідомлення про помилку в DOM у разі невдалого запиту.
- Реалізовано `initializeCatalog(products)` та `cardHTML(product)` для динамічної генерації карток із бейджем знижки, зірковим рейтингом, закресленою старою ціною (`<del>`) та умовною активацією кнопки «Додати в кошик».
- Налаштовано обробники подій (`input` для миттєвого пошуку і одночасних фільтрів, `change` для сортування), які викликають єдину функцію `renderCatalog()`.
- Реалізовано роботу кошика через `read()` / `write()` і `localStorage.getItem()` / `localStorage.setItem()` у `renderCart()`.

#### Запит 4 (Покращення UX, анімацій та обробки крайніх випадків):
> **Промпт до Gemini:**  
> *"Оптимізуй код script.js для кращого користувацького досвіду (UX): додай функції showLoader() та hideLoader() під час завантаження products.json, плавну анімацію появи карток товарів при перемальовуванні каталогу, інформативне повідомлення 'Товарів за вашим запитом не знайдено' з кнопкою скидання фільтрів, якщо відфільтрований масив порожній, а також функцію showNotification(text, type) на базі Bootstrap Alert/Toast при додаванні товару в кошик."*

**Виконані дії:**
- Інтегровано спінер завантаження (`#loader`) у блок `try / finally` функції `loadAndInitialize()` через `showLoader()` та `hideLoader()`.
- Додано плавний перехід прозорості (`opacity`) при рендерингу кожної картки товару.
- Додано обробку порожнього результату фільтрації з можливістю скинути всі фільтри в один клік.
- Реалізовано спливаючі сповіщення при кожному успішному додаванні товару до кошика.

### Етап 3: Налаштування, оптимізація та покращення UX

1. **Обробка подій та реактивне оновлення інтерфейсу:**
   - Ініціалізація каталогу та відновлення лічильника кошика прив'язані до події `DOMContentLoaded`.
   - Пошук за назвою (`product.name.toLowerCase().includes(query)`) спрацьовує миттєво при введенні кожного символу (`input` event) без перезавантаження сторінки.
   - Сортування підтримує 4 режими: за популярністю (`b.popularity - a.popularity`), за зростанням ціни (`a.price - b.price`), за спаданням ціни (`b.price - a.price`) та за поточним рейтингом (`average(b) - average(a)`).
2. **Робота з даними та відмовостійкість:**
   - Для захисту від пошкоджених даних у `localStorage` читання кошика обгорнуто в блок `try/catch`.
   - Якщо товар має `inStock: false`, його картка візуально приглушується, відображається статус «Немає в наявності», а кнопка додавання в кошик отримує атрибут `disabled`.
3. **Покращення візуального відгуку (UX):**
   - Під час виконання `fetch('products.json')` відображається індикатор завантаження Bootstrap (`spinner-border`), який гарантовано приховується у блоці `finally`.
   - При додаванні товару в кошик у правому верхньому куті екрана з'являється спливаюче повідомлення з назвою доданого гаджета, яке автоматично зникає через 3 секунди.
